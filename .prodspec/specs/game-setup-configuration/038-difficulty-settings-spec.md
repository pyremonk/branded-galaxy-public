# Difficulty Settings

## Overview

Difficulty Settings configure the parameters that govern the challenge level of a game session. Settings cover AI opponent behavior (covered in AI Strategy spec 032), galaxy size, starting resources, and victory condition thresholds. All difficulty settings are selected at game setup and persist for the duration of the game.

## Requirements

### FR-DS-001: Difficulty Presets
- System provides three named difficulty presets that bundle all settings:
  - **Easy**: Larger starting resources, smaller galaxy, generous victory thresholds, AI on Easy
  - **Standard**: Default values for all settings, AI on Medium
  - **Hard**: Fewer starting resources, larger galaxy, tighter victory thresholds, AI on Hard
- Players may select a preset or customize individual settings (Custom mode)
- The selected preset (or "Custom") is shown on the game summary screen before game start

### FR-DS-002: Galaxy Size Setting
- Options: Small (30–40 systems), Medium (50–70 systems), Large (80–100 systems)
- Default: Medium
- Galaxy size determines the number of systems generated by the galaxy generator (spec 001)
- Larger galaxies make the early game slower (longer travel times) and the late game denser

### FR-DS-003: Starting Resources Setting
- Options: Low / Standard / High (multiplier on faction starting resource values in faction definitions JSON)
  - Low: 0.75× all starting resources
  - Standard: 1.0×
  - High: 1.5× all starting resources
- Starting resources affect credits, materials, recruits, and influence equally
- The starting resource multiplier is applied to faction-specific starting values at game creation time

### FR-DS-004: Victory Condition Threshold Modifiers
- Certain victory conditions use numeric thresholds (e.g. "control X% of systems"):
  - Easy: thresholds reduced by 20% (e.g. control 45% instead of 55%)
  - Standard: default thresholds from victory conditions JSON (spec 008)
  - Hard: thresholds increased by 15% (harder to win, longer games)
- Threshold modifiers are applied at game creation and saved in game state; they do not change mid-game

### FR-DS-005: Individual Setting Controls
- In Custom mode, each setting can be adjusted independently:
  - Galaxy size: dropdown (Small / Medium / Large)
  - Starting resources: dropdown (Low / Standard / High)
  - Victory thresholds: slider (50% → 150% of standard values)
  - AI difficulty per slot: Easy / Medium / Hard (see spec 032)
- Custom settings are saved in game state for reference during play

### FR-DS-006: Difficulty Display in HUD
- The selected difficulty preset (or "Custom") is shown in the game settings overlay accessible from the HUD pause menu
- Individual settings are displayed (read-only) in the same overlay for reference

## Constraints

- Difficulty settings are locked once the game starts; no mid-game changes
- Custom settings must remain within defined bounds (no 0-resource starts, no impossible victory thresholds)
- Galaxy size selection must be passed to the galaxy generator at game creation time, not after

## Acceptance Criteria

- [ ] Easy preset applies Low resources, Small galaxy, -20% victory thresholds, AI Easy
- [ ] Standard preset uses default values from all config files
- [ ] Hard preset applies compressed resources, Large galaxy, +15% thresholds, AI Hard
- [ ] Custom mode allows independent adjustment of each setting
- [ ] Starting resource multiplier correctly adjusts all four resource types at game creation
- [ ] Victory threshold modifier saves in game state and is used by victory condition checks
- [ ] Difficulty is locked after game start; no modifications possible mid-game
- [ ] Difficulty summary is viewable in-game from the pause menu settings overlay
