# Feature Screenshot Images

Place PNG screenshots here to populate the landing page feature cards.
The Vite build serves this folder at `{BASE_URL}screenshots/<filename>`.

Expected filenames (matching `LandingPage.tsx` FEATURES array):

| File | Feature card |
|---|---|
| `galaxy-map.png` | Procedural Galaxy |
| `factions.png` | Three Asymmetric Factions |
| `fleet-combat.png` | Fleet Combat & Missions |
| `multiplayer.png` | Turn-Based ↔ Realtime Multiplayer |

If a file is missing the card falls back to a large Unicode icon automatically.
Recommended size: **960 × 540 px** (16:9). PNG or WebP.
