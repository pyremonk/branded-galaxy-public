# Character portraits (not included)

The game's character portraits come from a commercial asset pack,
[*Scifi Characters Icons* by Rexard](https://www.gamedevmarket.net/asset/scifi-characters-icons-8706),
licensed under the GameDev Market Pro Licence. That licence doesn't allow redistributing
the files, so they aren't in this repository.

Without them, the game shows a generic silhouette wherever a portrait would appear
(see `src/utils/portrait.ts`). If you own the pack, drop its transparent PNGs here
using the filenames listed in `core/character-state-manager.ts`.
